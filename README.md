# MobiLoom

**A reproducible recovery of the Mobile Studio for Android APK.**

MobiLoom is the name of this open-source recovery project. The application itself is still the original **Mobile Studio v1.1**: its package name, resources, assets, and recovered application code have not been redesigned or rebranded.

This repository exists to make the supplied APK easier to inspect, rebuild, and maintain. It includes the decoded Android resources and manifest, app assets, native libraries, and Smali representation of the bytecode, together with a GitHub Actions workflow that produces a debug-signed APK.

> **Important:** an APK is a compiled application, not an Android Studio project. The original Kotlin/Java source project was not present in the supplied APK, so this repository does not claim to contain the developer's original source code.

## Download

The latest published debug build is available from the repository's **Releases** page. Download `mobile-studio-debug.apk` from the release assets and install it on a compatible Android device.

The APK is signed with a temporary Android debug key generated by the build workflow. It is not signed with the original developer's private signing key. If you already have another installation signed with a different key, Android may require you to uninstall that copy before installing this build.

## Building from source

The repository contains the decoded project under `app/`. To create a fresh debug build:

1. Open the **Actions** tab on GitHub.
2. Select **Build Mobile Studio APK**.
3. Choose **Run workflow** and start the workflow on the `main` branch.
4. When the run finishes successfully, open the run's **Artifacts** section and download `mobile-studio-debug-apk`.

The workflow rebuilds the decoded project with Apktool, aligns the APK, creates a temporary debug signing key, signs the output, and verifies the signature. The generated signing key is intentionally not committed to this repository.

## Recovery notes and limitations

The supplied APK was analyzed with [REA](https://github.com/morluto/rea) and JADX. The recovery process preserves the APK's available components; it does not recreate missing original project files or guarantee that every behavior can be edited as clean Kotlin or Java source.
